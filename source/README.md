# Aster source

`build.py` assembles these files into one self-contained page:

- `src/shell.html` the page skeleton (header, search, display settings, the Explore sheet, the phone bar and the dialogs); `src/views/*.html` one file per page, in order
- `src/aster.css` Aster's design system, written for this app; `src/palettes.css` the four palettes (Violet, Sky, Rose and Quiet), each light and dark, generated by `tools/palettes.py`, which checks WCAG AA contrast for every text pair; `src/app.css` the diagrams, tools and interactive pieces
- `tools/chartcolors.py` picks the chart colours for every palette and checks them with the data-visualisation validator (lightness band, chroma, colour-blind separation, contrast)
- `src/js/*.js` scripts, joined in a fixed order inside one closure. `bloom.js` draws the bloom: a petal for each moment marked, with a golden centre laid out by Vogel's 1979 model of a flower head (each floret turned 137.5 degrees from the last). Section 6 of `diagrams.js` draws the seven stages as a growth series, from seed to full flower
- `src/refs.js` the evidence library, generated by `evidence/cite.py` from `evidence/refs_aster.py` and the PubMed records in `evidence/records.json` (retrieved and checked on 21 November 2026)
- `tools/fig/figure.py` draws the human figure used in the body map, the arm-movement diagram and the breathing diagram, and writes `src/js/figure.data.js`: `python3 tools/fig/figure.py src/js/figure.data.js`
- `tools/icons.py` makes the app icons; `tools/pwa_shots.py` makes the install previews and the link-sharing picture
- `fonts/` the embedded open-licence fonts (SIL Open Font License 1.1): Bricolage Grotesque for headings and Figtree for reading
- `tools/render.py`, `tools/interact.py` and `tools/axe.py` the checks used before release: screenshots of every page in every palette, light and dark, at desktop and phone widths; interaction tests; and automated accessibility checks

To rebuild: `python3 build.py "out/Aster v2.html"`, then put the new file in `../versions/` and run `python3 ../tools/build_site.py`.
